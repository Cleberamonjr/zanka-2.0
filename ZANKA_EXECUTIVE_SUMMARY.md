A: Yes, but NEJI audits 100% of work daily. You get alerts for any issues. Manual approval required for high-impact decisions.

**Q: What if an agent fails?**  
A: HECTOR (Claude) auto-detects failures and attempts fixes. Slack alerts you. Auto-retry 3x before escalation.

**Q: Can I pause specific agents?**  
A: Yes. Slash command in Slack: `/zanka pause-luna` to pause LUNA specifically.

**Q: How do I track ROI by agent?**  
A: DIANA generates daily reports. Google Sheets shows "Agent ROI" dashboard. Each agent's contribution is tracked.

**Q: Is my data safe?**  
A: All data in Supabase (encrypted, backed up, SOC 2 compliant). API keys in .env (never logged). Audit trail for every decision.
