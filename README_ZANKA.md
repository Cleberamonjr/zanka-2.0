→ Test webhook: `curl -X POST [WEBHOOK_URL] -d '{"text":"Test"}'`  
→ Verify bot token in .env  
→ Check channel permissions

→ Check Supabase status page  
→ Increase Zapier timeout (30s → 60s)  
→ Reduce query complexity
